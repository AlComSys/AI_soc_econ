# The simple impact of AI
Программное средство ImpactCalc.py предназначено для вычисления приблизительного диапазона потенциальной экономической выгоды (валовой добавленной стоимости) от внедрения ИИ-основанных подходов (машинного обучения) для решения определенной технической задачи. Вычисления основаны на простой модели, учитывающий следующие три компоненты: экономический вес задачи (уровень конвертируемости потенциального прироста в ВДС), ожидаемое улучшение заданной задачи алгоритмом машинного обучения, а также вероятность реализации качественного внедрения.

* ImpactCalc.py - программный модуль для вычисления диапазона потенциальной выгоды от внедрения ИИ
* Руководство пользователя.docx - описание основных шагов использования, разбор ключевых функций, а также рассмотрение математического аппарата
